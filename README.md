# PlanckFrames (PFStudio)

Studio site for the apps built under PlanckFrames / PFStudio.

- Foliosyne
- Sablepane
- Crypto Galaxy
- Crypto Chains
- Crypto Pies

## Local

```bash
npm install
npm run dev
```

## Deploy

Import this repository in [Vercel](https://vercel.com/new). Framework preset: Next.js. Root directory: `.`
